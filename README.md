🚀 Apprentissage de JavaScript

Exploration et apprentissage du langage JavaScript, en mettant en pratique des concepts fondamentaux et avancés à travers divers exercices et projets interactifs.

🚀 Installation

Cloner le dépôt :

```
  git clone https://github.com/utilisateur/apprentissage-javascript.git
```

🎯 Objectif du Projet

Ce projet vise à acquérir une compréhension approfondie de JavaScript, en appliquant ses fonctionnalités à des exercices pratiques et des mini-projets interactifs.

🛠 Technologies utilisées

⚡ JavaScript (ES6+) – Langage principal pour le développement web<br>
🌍 HTML, CSS – Structure et styles de l'application<br>
🔧 Live Server – Rechargement automatique des modifications<br>

✨ Fonctionnalités

✅ Exercices interactifs pour chaque concept <br>
✅ Prise en main du Modèle, Vue, Controller <br>
✅ Gestion d'événements et animations dynamiques <br>
✅ Requêtes API et manipulation de données JSON <br>
